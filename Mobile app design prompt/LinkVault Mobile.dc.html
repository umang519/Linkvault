LINKVAULT
MOBILE UI

Save a link in seconds. Find exactly what you need later. Every screen below is built on the Modernist system — flat surfaces, zero radius, 2px rules, one red accent, Archivo throughout, and no icons: rank, count and rule weight do the work icons usually do.

Assumptions
One user, one vault, no sharing. v1 scope from PLAN.md §1; metadata fetch, duplicate detection and collections are drawn as V2 so the shell doesn't have to change later. iOS geometry (390×844), safe areas respected.
Navigation
Five tabs — Home, Search, Browse, Saved, You — with a red Save Link block floating at bottom-right, inside thumb reach on a large phone. Browse holds Categories, Collections and Tags behind one chip row; Saved holds Favorites and Status. Nothing is buried more than two taps deep.
Retrieval-first decisions
Home leads with four counts — favorites, to read, categories, tags — because each is a way back in. Search states which fields it covered. The filter sheet always shows the resulting count before you commit. Status and favorite stay separate axes.
